What the prototype measures

Education

Average of total literacy, female literacy and gender parity. Census 2023.

Health

Relative index of listed public health facilities per 100,000 people within these ten districts. It does not measure care quality.

Accountability

Average overall and development-budget utilization. Spending money is not proof that it was spent well.

Why GPIS exists

Democracy needs an informed public.

Accountability is harder when people cannot see how public services are performing or how public money is used. When evidence is difficult to access, slogans and selective claims can take the place of informed debate.

GPIS aims to make official information easier to find, compare and question, so citizens can assess claims, ask better questions of their representatives and take part in public life with evidence in hand.

District indicators describe measured conditions and selected financial records. They do not, on their own, establish which politician caused an outcome, prove misconduct or tell anyone how to vote.

From official records to answers

How GPIS and Ask GPIS work

Ask GPIS uses retrieval-augmented generation (RAG): it looks up relevant evidence before an AI model writes an explanation. You can open the citations to inspect the sources behind an answer.

  1. 1. Collect and validate

    Source-specific parsers read supported official census files. Other evidence is manually reviewed. District names, values and periods are checked, and source locations are preserved.

  2. 2. Store and calculate

    PostgreSQL stores observations, sources and evidence. Python calculates scores and period changes using defined rules. Missing inputs stay missing; the AI does not calculate or change scores.

  3. 3. Retrieve the evidence

    Structured queries supply exact facts, rankings and trends. For explanations, keyword search and semantic search find relevant passages by wording and meaning.

  4. 4. Explain with citations

    The assistant uses the retrieved results to answer, with links to the evidence. If the AI is unavailable or its answer fails validation, GPIS uses a source-based fallback or says there is not enough evidence.

Technical architecture

The HTML, CSS and JavaScript interface calls a FastAPI backend. LangGraph coordinates a bounded assistant with three LangChain tools: district data, evidence search and project knowledge. PostgreSQL full-text search and pgvector similarity search using MiniLM embeddings provide hybrid retrieval; reciprocal-rank fusion combines their results. Groq supplies the language model when configured.

PostgreSQL checkpoints retain conversations, and optional Redis caching speeds up repeated retrieval. The JSON repository supports development without a database. Citations retain source titles, publishers, reporting periods and table or page locations so answers can be checked. Citations improve traceability; they do not guarantee that every explanation is correct.
