# Changelog

All notable user-visible changes will be documented here.

## [Unreleased]

### Added

- FastAPI `/api/v1` contracts, structured errors, request IDs, and static UI serving.
- PostgreSQL/pgvector schema, Alembic migration, Docker Compose, and idempotent seed/bootstrap commands.
- Persisted versioned scores and 384-dimensional local MiniLM embeddings.
- Hybrid structured, full-text, and vector retrieval with RRF and metadata filters.
- Optional Groq generation with strict citation validation, retry, fallback, and abstention.
- Thirty-question RAG evaluation, provider failure tests, integration tests, and CI.

## [0.1.0] - 2026-08-20

### Added

- Five-district South Punjab dashboard.
- Education, health-access, financial-management, and overall scores.
- District/category rankings.
- Official source links and evidence locators.
- Citation-grounded evidence assistant with abstention.
- Dependency-free Python server and responsive browser UI.
- Initial automated test suite and project documentation.
